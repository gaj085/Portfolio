# Gajendra Verma — Software Engineer & Developer Portfolio

A modern, responsive, and high-performance personal portfolio built with React, Vite, and custom CSS design tokens. Engineered to highlight full-stack projects, competitive programming milestones, and technical achievements for recruiters and tech leaders.

---

## ⚡ Highlights

- **Hero & Identity**: Clean architecture backdrop framing profile portrait with quick stat callouts (8.99 CGPA, 500+ DSA Solved, 1900 Chess.com Peak Rating).
- **Projects Showcase**: Interactive project cards featuring Konnect, StudyStream, Forensight, and MFCC Speaker Recognition with expandable technical breakdown drawers.
- **Dynamic Resume**: One-click resume access integrated with cloud versioning for instant updates without code deployments.
- **Skills Matrix**: Categorized tech stack covering Frontend, Backend, Databases, Tools & Core CS Fundamentals.
- **Fully Responsive & Accessible**: Custom CSS design system, dark mode palette, smooth scroll navigation, and WCAG-compliant contrasts.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Vanilla CSS Design System
- **Fonts**: Inter & Outfit (Google Fonts)
- **Deployment Ready**: Vercel / Netlify / GitHub Pages

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   cd Client
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
